# Paper completion checkpoint

The new manuscript focuses on minimum storage for exact historical ML recovery under bounded loss of declared replay capability groups
The earlier milestone paper remains available as its own completed checkpoint

## Three specific contributions

1. One shared byte retention model protects all historical targets under every allowed correlated tool loss set and includes source and metadata costs
2. A closed set counterexample optimizer proves the minimum store at certified termination and an indexed executor preserves the exact grounded recovery certificate
3. A reproducible comparison studies the price of resilience using original published materialization code and native snapshot software and an independent exact model and real trained model payloads

These contributions are supported by formulation and proof and working code and raw experiments
They do not establish first ever invention of materialization or alternate producers or Horn cuts or counterexample guided synthesis

## Evidence that changes the assessment

The corrected tabular study has 24 captured histories and 48 planning cases and 28512 requests across nine policies
The proposed method and independent exact model each restore all 3168 requests and agree on every minimum byte total
Mean saving against full target snapshots is 20.264 percent
The two original HYPPO materializers restore 2069 and 2145 requests at the same robust minimum budget limits

The larger forest and neural experiment has four captured histories and eight cases and 1584 requests across nine policies
The proposed method restores all 176 requests and agrees with the independent exact model
One loss forest snapshot saving is 90.628 percent and one loss neural saving is 36.357 percent
Two loss neural saving is zero and this control is retained

All sixty planner scaling runs match an independent analytic minimum
The 24 group two loss case has 301 allowed scenarios and the expanded formulation has 27255 variables while our master has seventeen and the adversary has forty one
Our median total planning time is 29.86 milliseconds versus 680.10 milliseconds for the expanded formulation
At six groups and one loss enumeration is faster and the paper reports this outcome

The dependency chain kernel preserves all certificate steps and reaches a 434.89 times median kernel speedup at depth 2048
This is a generated certificate kernel result and is not a full restoration or general workflow speedup

## Resolved defects and controls

The original HYPPO component strict capacity test was normalized to the common inclusive integer byte budget and a separate sum check prevents awarding an extra usable byte
The thirty two case pre normalization protocol pilot is preserved and excluded from final claims
The first larger estimator run stopped at a neural pickle round trip byte mismatch and is preserved as a failed diagnostic
The corrected neural artifact is a canonical inference checkpoint and exact native model predictions are checked at capture and loaded checkpoint byte round trips are tested
This checkpoint supports exact inference and does not claim optimizer state for training resume

The primary tabular and corrected estimator runs record different source versions and their exact dependencies are saved so provenance remains inspectable
No old execution environment or output hash was edited to turn a failure into a success
