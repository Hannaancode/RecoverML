## Dataset and application citations

Use the existing data provenance records in the retinal and Letter artifacts
for the exact public STARE images, masks and UCI Letter release used. Cite
EyeAI as motivation only after verifying its primary source and the historical
feature-extraction account already recorded in the project. The new workflow
is inspired by that application and was not run on its private clinical data.
Wine and Breast Cancer experiments are constructed version histories from
public benchmark datasets rather than independently observed laboratory
histories. Cite dataset sources and scikit-learn separately from the reuse
systems being compared.
