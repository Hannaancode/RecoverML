# Frozen storage transfer, 26 October 2026

This follows the lossless-store engineering experiment with every older frozen condition:
48 scientific, 72 separate/shared multiview, 108 retinal and two Letter conditions.
`configs/encoded_storage_transfer_oct26.json` fixes the complete 230-condition denominator.

Read original manifests, contracts, raw minima and captured payloads from their existing hash-bound evidence.
Decode no pickle and fit no model. Encode each available canonical payload once with the adaptive and stronger gzip policies.
Save all actual encoded bytes, original input hashes, source snapshots, selected-file inventories and scenario certificates.
Where every candidate is available, reoptimize exact byte costs, check with the separate scenario formulation,
and compare same-codec strong local search, snapshots and encoding the raw optimum without reselecting.

Availability states are part of the result:

- `COMPLETE`: all candidate payloads exist and both encoded optima can be measured.
- `SELECTED_ONLY`: the existing raw optimum's files exist, but other candidates are missing; measure that actual reencoded store without claiming an encoded optimum.
- `UNAVAILABLE`: even the raw selected set is incomplete; no hypothetical saving is substituted.

Unavailable conditions remain nonwins in full-denominator saving rates.
The incomplete original large Letter archive is not declared repaired by this experiment.
Encoded representations preserve original payload hashes and conditional reachability, but these byte-level checks are not new end-to-end model recovery requests.
Fresh supported-runtime recovery is tested separately by the complete 72-capture storage census.
Manual optima still tie when given the same encoding options; standard compression is credited rather than claimed as new research.

The [completed result](../results/research/encoded_storage_oct26/RESULTS.md) has 228 full encoded objectives,
one selected-only Letter measurement and one unavailable Letter selected store.
All four original cloud jobs and their independent audits passed; missing data remains a recorded outcome rather than an audit failure or a fabricated value.
